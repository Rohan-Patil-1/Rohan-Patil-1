## About Me

M.S. in Computer Science, DePaul University. NIH-funded research on deep learning for medical imaging, metric learning, and explainable AI.

## Building

**[Daily AI News Agent](https://github.com/Rohan-Patil-1/AI-news-agent)** — automated daily pipeline (GitHub Actions cron) that pulls AI news from RSS feeds and Hacker News, dedupes, and uses Gemini to rank the top 5 stories by significance with reasoning attached. Writes and auto-commits a markdown digest daily.

## Research

- **VS-EDGE** — Siamese network + VAE augmentation for lung nodule spiculation classification, LIDC-IDRI. Accepted IEEE eScience 2026. [Repo](https://github.com/Rohan-Patil-1/Semantic-Similarity-based-Classifier)
- **FPI-6** — automated Foot Posture Index (FPI-6) scoring, ResNet50 + Bio_ClinicalBERT. 
- **ViSTa-PD** — TCN framework translating video to sensor signals for Parkinson's motor assessment. Accepted IEEE MMSP 2026.
